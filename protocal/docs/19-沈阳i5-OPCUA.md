# 19 · 沈阳机床 i5（OPC UA）实现规格书

> **证据**：🟢参考实现`libi5-opcua.so` + 端口 4840
> **定位**：沈阳机床 i5 系列智能机床 —— **走标准 OPC UA，实现与 840D 同栈**

---

## 1. 速查

| 项 | 值 |
|---|---|
| 端口 | **TCP 4840**（OPC UA Binary） |
| 端点 | `opc.tcp://<ip>:4840` |
| 实现库 |参考实现`libi5-opcua.so` |
|参考实现| `asyncua`（Python，同 840D） |

---

## 2. 连接与节点

```
① 用 asyncua/任何 OPC UA 客户端连 opc.tcp://<ip>:4840
② Browse 根节点 → 找 i5 命名空间（厂商特定命名空间）
③ 读数据节点 / 建订阅
```

**与 840D 的差异**：仅**命名空间与节点树结构**不同，传输层与 API 完全一致 —— **同一套 OPC UA 客户端代码可复用**（只需换节点路径配置）。

---

## 3. 采集建议

| 项 | 建议 |
|---|---|
| 方式 | **订阅（Subscription）优先**，发布间隔 100-500ms |
| 断线 | 自动重连 + 重新建订阅（OPC UA 不自动恢复订阅） |
| 节点发现 | 首次上线时 Browse 全树并缓存到配置（避免每次硬编码） |
| 写操作 | i5 的写节点需权限验证，默认只读 |

---

## 4. 实现坑

1. **节点路径厂商私有** —— 必须现场 Browse 探测，不能照搬 840D 的路径。
2. **i5 的部分数据不在 OPC UA 暴露**（如某些 PLC 内部量），需辅以 Modbus/S7 读取。
3. **会话保活**：OPC UA 会话超时（默认 60 min），要定时 KeepAlive。
4. **证书信任**：若机床启用了安全策略，客户端需导入证书（`SessionSecurity`）。
5. **同一台机床可能同时开 OPC UA + Modbus** —— 可按数据面选择（OPC UA 拿 CNC 量、Modbus 拿 PLC 量）。
