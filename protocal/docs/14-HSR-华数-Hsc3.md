# 14 · 华数机器人 HSR（Hsc3Api）实现规格书

> **证据**：🟢参考实现`libHsc3Api.so` + `libCommApi.so`（12 个代理域 ~170 方法）
> **定位**：国产机器人（**华数机器人 HSR**，华南机器人品牌）主流接口
> **注意**：华数机器人 ≠ 华中数控（HNC）。华中数控是 CNC 系统厂商（其 hncAPI 因 Windows-only 已否决，见 [21 册](21-品牌缺口盘点.md)）；华数机器人的 Hsc3Api 是 **Linux `.so`**，可跨平台调用，**不受此否决影响**。

---

## 1. 速查

| 项 | 值 |
|---|---|
| 端口 | **UDP 23234** |
| 传输 | UDP（另有 TCP 变体） |
| 库 | `libHsc3Api.so`（业务） + `libCommApi.so`（通信底座） |
| 代理域 | **12 个**（~170 方法） |
| 参考实现侧 | `libhsr3` 系 + `/HSR/*` 驱动 |

---

## 2. 代理域（12 个）

| # | 代理域 | 能力 |
|---|---|---|
| 1 | 系统（System） | 版本、状态、模式、时钟 |
| 2 | 运动（Motion） | 关节/笛卡尔运动、点位 |
| 3 | **状态（RobotStatus）** | 坐标、速度、负载、使能 |
| 4 | **IO** | 数字/模拟输入输出 |
| 5 | **变量（Variable）** | 系统变量/用户变量读写 |
| 6 | 程序（Program） | 程序列表、执行控制 |
| 7 | 报警（Alarm） | 当前/历史报警、清除 |
| 8 | 参数（Parameter） | 机器人参数读取 |
| 9 | 伺服（Servo） | 伺服状态/参数 |
| 10 | 轨迹（Trajectory） | 轨迹信息 |
| 11 | 标定（Calibration） | 工具/工件坐标 |
| 12 | 扩展（Extension） | 厂商扩展接口 |

> 具体方法名 ~170 条（原始素材未随本目录提供）

---

## 3. 通信模型

```
Hsc3Api（业务层，12 代理域）
    ↓
CommApi（通信层：连接管理/打包/重传/心跳）
    ↓
UDP 23234（无连接）
```

**要点**：
- 业务调用**异步化**：多数接口是 `Request/Response` 或回调（`Callback` 注册）
- 连接需先 `Connect(ip, port)` 建立会话；`m_Connected` 状态
- 心跳/看门狗由 CommApi 维护

---

## 4. 典型流程

```
① CommApi.Connect(ip, 23234)
② 注册回调：AlarmCallback / StatusCallback（可选，接收推送）
③ 业务调用：
     状态： RobotStatus 代理 → 取关节角/笛卡尔坐标/IO
     变量： Variable 代理 → ReadVariable(name) / WriteVariable(name, value)
     报警： Alarm 代理 → GetCurrentAlarms()
④ 断开： Disconnect()
```

---

## 5. 实现坑

1. **UDP 环境**：需自己做超时重传与序号校验（同安川 HSES）。
2. **回调驱动 vs 轮询**：华数接口偏回调，若用轮询需注意内部缓冲可能溢出。
3. **库为 Linux ARM/x86 `.so`** —— 跨平台需重新编译或走 TCP 桥接。
4. **变量命名体系**：华数变量名（如 `$AXIS_ACT` 风格或自定义）需查厂商手册。
5. **使能/上电状态**：读坐标前需确认机器人已使能，否则返回无效值。
6. **报警清除需权限**（部分型号）。
