# 26 · 马扎克 MAZAK 实现规格书

> **证据**：🟡 公开实证（免授权采集方案 + 参数/端口细节）
> **门槛核验**：✅ **跨平台**（纯 Socket）· ✅ **免授权** · ✅ **可自实现**（TM 授权费 ~1.2 万可规避）
> **注意**：**仅 Smart / Smooth 系列合格**；640 / MATRIX（NEXUS）走 Windows 插件，**不满足跨平台**

---

## 1. 速查

| 项 | 值 |
|---|---|
| 合格系列 | **Smart** · **Smooth**（smooth-c / smooth-g / smooth-x） |
| 不合格系列 | 640（640m/640mn/640t）· MATRIX（nexus/nexu2）—— Windows 装插件 + UDP 上报 |
| 主协议 | **TCP 直连**（纯 Socket，**无需 DLL、无需授权**） |
| 端口 | **50100**（Smooth 系列固定端口，需在机床参数确认未被改） |
| 前置开关 | **IOP4.0 = 1**（Smooth）/ **IOP5 = ~00000100~**（Smart，启用以太网） |
| 网络解锁 | Smart 系列：机械参数输入**解锁码 1131** 后重启，才出现以太网选项 |
| 备选路线 | MTConnect（需 ~8000-12000 授权，或改造规避） |
| 授权费 | 官方 MT 协议约 **¥8000-12000** + 服务费（TCP 直连可完全规避） |

## 2. 三条路线对比

| 路线 | 跨平台 | 授权 | 适用系列 | 评价 |
|---|---|---|---|---|
| **① TCP 直连** ★★★ | ✅ Linux/ARM/单片机 | **免** | **Smart / Smooth** | **首选** —— 纯 Socket，任何语言可实现 |
| ② MTConnect | ✅（HTTP/XML） | ✗ 需授权（~1.2万） | 多系列 | 可但贵；亦可改造规避 |
| ③ DLL 调用 | ✗ **仅 Windows 32 位** | — | — | 排除 |

## 3. 机床侧开启（分系列）

### 3.1 Smart 系列

```
① 按【数据输入/输出】键
② 若未见以太网选项 → 进入【机械参数输入】→ 输入解锁码 【1131】→ 重启
③ 设置 IOP5 = ~00000100~   （启用以太网）
④ 设置机床 IP（与采集机同网段）
⑤ 确认 TCP 端口（默认 50100）
```

### 3.2 Smooth 系列

```
① 设置机床 IP
② 开启 【IOP4.0 = 1】
③ 确认端口 50100 未被修改
```

## 4. 采集实现

```
① TCP connect(<机床IP>, 50100)
② 按协议发送请求 / 或接收周期上报帧（视固件配置）
③ 解析数据：坐标 / 主轴 / 进给 / 状态 / 报警 / 程序
④ 采集周期建议 500-1000ms
```

**MTConnect 路线**（若已开通或改造）：
- dataItemId 表按系列区分：**Matrix 1&2（V1.2 版）** · **Smooth X & G（V1.3）** · **Smooth C（V1.3）**
- 端口/HTTP 路径遵循 MTConnect 标准（见 [16 册](16-MTCONNECT.md)）

> ⚠️ **报文格式缺口**：TCP 直连的**帧结构**未公开获取（属付费方案核心）。
> 补齐方式：现场抓包 + 状态变更比对法（同 [24 册 宝元](24-宝元LNC.md) §6 的 5 步法）。

## 5. 实现坑

1. **系列决定可行性**：先确认机床是 Smart/Smooth 还是 640/MATRIX —— 后者**必须排除**（Windows-only 路线）。
2. **IOP 参数是开关**：不开 IOP4.0/IOP5，端口根本不监听。
3. **Smart 需解锁码 1131** 才能看到以太网选项。
4. **端口 50100 可能被改** —— 现场必须在参数页确认。
5. **不要走 DLL 路线**（Windows 32 位限制）。
6. **MT 授权费 ~1.2 万** —— 首次实施前先确认客户机床是否已开通，避免重复采购。
