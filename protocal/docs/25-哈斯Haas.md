# 26 · 哈斯 Haas（MDC）实现规格书

> **证据**：🟡 公开实证（采集教程 + 实战文章）· 关键参数与数据点清单已确认
> **定位**：**西方最大机床厂**（美国），采集**无专用开发包、免授权**，是欧美客户群的必选项

---

## 1. 速查

| 项 | 值 |
|---|---|
| 机床 | Haas 全系（新版支持网口；老版走串口） |
| 前置功能 | **MDC（Machine Data Collection）** —— 在机床参数里开启 |
| **关键参数** | **参数 143** = 通信端口（**设为非零值**即启用 MDC 并指定端口） |
| 协议 | **TCP**（文本命令） |
| 命令 | **Q / E 指令**（发送后机床返回数据） |
| 授权 | **免授权**（无需厂家开发包） |

---

## 2. 开启与连接（机床侧）

```
① 【设置】→【网络】→【有线连接】→ 设置 IP/子网掩码（与采集机同网段）
② 【设置】→ 参数 → 找到 143 → 设为非零值（该值即监听的 TCP 端口号）
③ 采集机 TCP 连接 <机床IP>:<143 设的端口>
④ 发送测试指令，有返回即链路通
```

> **参数 143 = 端口号**是 Haas 采集的核心开关，也是与其它品牌最大的不同（其它品牌有固定端口）。

---

## 3. 数据点（已验证可采集项）

| 类别 | 数据项 |
|---|---|
| 生产 | **产量（工件计数）**、**状态（运行/停止/报警）** |
| 坐标 | **各轴坐标** |
| 负载 | **轴负载** |
| 主轴 | **主轴转速** |
| 倍率 | **主轴倍率 · 进给倍率 · 快速倍率**（三个倍率，Haas 特色齐全） |
| 进给 | **进给速度** |
| 程序 | **当前程序名 / 程序号 · 当前程序块（行号）** |
| 刀具 | **刀具信息**（刀补读写有专题实践） |

---

## 4. 命令与报文

| 项 | 说明 |
|---|---|
| 命令形式 | **Q 指令 / E 指令**（文本） |
| 响应 | 文本数据（按指令返回对应内容） |
| 连接 | 长连接 TCP；建议采集周期 500-1000ms |

**用法示意**：
```
→ Q100\n            （读取某类数据）
← <数据文本>\n
```

> ⚠️ **Q/E 指令的完整码表未公开**（在 Haas 的 MDC 文档/收费资料中）。现有实证只到"用 Q/E 指令提取数据"这一层。
> 补齐方式见 §6。

---

## 5. 实现坑

1. **参数 143 必须非零**，否则端口不监听 —— 这是"连不上"的第一排查点。
2. **端口不是固定的**（143 参数决定）→ 设备配置里必须记录该值。
3. **文本协议**：响应解析要容错（不同固件版本字段顺序/分隔符可能不同）。
4. **老机床**（无网口）走**串口**，协议与网口版不同 —— 需按机型分支。
5. **Q/E 指令语义需逐条验证**：先用测试指令确认链路，再逐条比对返回内容与面板显示值。
6. **写类操作**（刀补写入有实践案例）需谨慎，生产默认只读。

---

## 6. 补齐路径（从 🟡 升到 🟢）

```
① 现场抓包：开好 MDC 后抓 TCP 流量，逐条记录 "发 Qxx → 收 yyy" 的对应关系
② 状态变更比对：改变机床状态（启动/停止/改倍率/换程序），观察哪些指令的返回变化
③ 面板校验：把返回数值与机床面板显示值对照，确定缩放系数（Haas 常带小数位）
④ 汇总成"指令码 → 数据项 → 解析格式"表 → 升级为 🟢 级规格书
```
