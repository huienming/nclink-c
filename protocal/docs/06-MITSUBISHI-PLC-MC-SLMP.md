# 06 · 三菱 PLC（MC 协议 / SLMP）实现规格书

> **证据**：🟢参考实现参考实现 Melsec McFrame/McBinary/McCommand 构造器 + pymcprotocol/melsec_mc_protocol 源码
> **定位**：三菱 PLC 全系（Q/L/FX5U/iQ-R/iQ-F）标准以太网协议

---

## 1. 速查

| 项 | 值 |
|---|---|
| 端口 | **TCP/UDP 5534**（SLMP 常见 5007；FX5U 常用 5000/5001） |
| 帧型 | **3E**（QnA 兼容，主流）· **4E**（iQ-R 带序列号）· **1E**（A 系列）· **3C**（串口） |
| 编码 | **二进制**（推荐）或 **ASCII** |
| 字节序 | 二进制帧**小端**；ASCII 帧大端数字文本 |
|参考实现| `pymcprotocol` · `melsec_mc_protocol` |
| 参考实现侧 | `/Mitsubishi/PLC/*` 驱动（端口 5534） |

---

## 2. 连接建立

```
① TCP connect(ip, 5534)   —— 或 UDP 5534
② 无握手，直接发命令帧
③ 保活：定时发 0x0619（环回测试）或读一个固定地址
```

**注意**：MC 协议**无会话概念**，每个请求自包含；UDP 更快但需自己处理丢包重试。

---

## 3. 帧格式

### 3.1 3E 二进制帧（请求）

```
偏移  长度  内容            说明
0     2    D0 00           子头（3E 二进制固定 0x00D0 → 小端 D0 00）
2     1    网络号           通常 0x00
3     1    PLC 号           通常 0xFF（自站）
4     2    请求目标模块     0x03FF → FF 03（小端）
6     1    请求目标站号     通常 0x00
7     1    请求数据长度     命令+子命令+数据 的字节数（小端 2 字节前？见下）
8     2    监视定时器       0x0010（4 秒）
10    2    命令码           如 0x0401（小端 01 04）
12    2    子命令码         如 0x0000（小端 00 00）
14    N    数据区（地址+点数）
```

> ⚠️ **字节 7 起的长度字段是 2 字节小端**（覆盖 `定时器 + 命令 + 子命令 + 数据`），实现时按 `len = 2 + 2 + 2 + len(data)` 计算。

### 3.2 响应（3E 二进制）

```
0     2    D0 00            子头
2     1    网络号            回显
3     1    PLC 号            回显
4     2    请求目标模块      回显
6     1    请求目标站号      回显（+0x80 若出错？）
7     2    响应数据长度
9     2    结束代码          0x0000 = 正常
11    N    数据区
```

### 3.3 4E 帧（iQ-R）

在子头后增加 **2 字节序列号**（请求自增，响应回显），其余同 3E。

### 3.4 1E 帧（A 系列）

```
子头 0x00 0x00 + 网络号 + PLC号 + 目标模块 + 站号 + 数据长度(2) + 监视定时器(2) + 命令(2) + 子命令(2) + 数据
```
（1E 无子头 D0 00，直接 0x00 0x00）

## 4. 命令码表

| 命令码 | 子命令 | 功能 |
|---|---|---|
| `0x0401` | `0x0000` | **成批读**（按字/位） |
| `0x0401` | `0x0001` | 成批读（位单位） |
| `0x1401` | `0x0000` | **成批写** |
| `0x1401` | `0x0001` | 成批写（位单位） |
| `0x0403` | — | 随机读（多个不连续地址） |
| `0x1402` | — | 随机写 |
| `0x0619` | — | **环回测试**（保活用） |
| `0x0611` | — | 清 CPU 错误 |
| `0x1001` | — | 远程 RUN |
| `0x1002` | — | 远程 STOP |
| `0x1003` | — | 远程 RESET |
| `0x1005` | — | 读 CPU 型号 |
| `0x0101` | — | 读 CPU 状态 |

## 5. 地址格式

### 5.1 设备码（二进制帧 1 字节）

| 设备 | 码 | 单位 | 设备 | 码 | 单位 |
|---|---|---|---|---|---|
| SM（特殊继电器） | `0x91` | 位 | D（数据寄存器） | `0xA8` | 字 |
| SD（特殊寄存器） | `0xA9` | 字 | X（输入） | `0x9C` | 位 |
| Y（输出） | `0x9D` | 位 | M（内部继电器） | `0x90` | 位 |
| L（锁存继电器） | `0x92` | 位 | F（报警器） | `0x93` | 位 |
| V（边沿继电器） | `0x94` | 位 | B（链接继电器） | `0xA0` | 位 |
| R（文件寄存器） | `0xAF` | 字 | W（链接寄存器） | `0xB4` | 字 |
| TN（定时器当前值） | `0xC2` | 字 | TS（定时器触点） | `0xC1` | 位 |
| CN（计数器当前值） | `0xC5` | 字 | CS（计数器触点） | `0xC4` | 位 |
| ZR（文件寄存器扩展） | `0xB0` | 字 | — | — | — |

### 5.2 地址编码（二进制，3 字节）

```
字节 0    : 设备码
字节 1-2  : 起始地址（小端），字单位
位设备：地址 × 16 + 位号（例：M100 → 0x0640）
```

**ASCII 帧**：设备名（如 `D`）+ 地址（6 位十六进制）+ 长度 —— 例 `0401 0000 D*001000 0001`

## 6. 读写流程（二进制 3E，读 D100 起 4 字）

```
请求：
  D0 00            # 子头
  00               # 网络号
  FF               # PLC 号
  FF 03            # 目标模块
  00               # 站号
  0C 00            # 数据长度 = 12（定时器2 + 命令2 + 子命令2 + 数据6）
  10 00            # 监视定时器
  01 04            # 命令 0x0401
  00 00            # 子命令
  A8               # 设备码 D
  64 00            # 起始地址 100（小端）
  04 00            # 点数 4
响应：
  D0 00 00 FF FF 03 00 09 00 00 00 <8 字节数据>   # 结束代码 0000 = OK
```

**批量读上限**：单请求 ≤ **960 字**（1920 字节）—— 超了分片。

## 7. 错误码（结束代码）

| 码 | 含义 |
|---|---|
| `0x0000` | 正常 |
| `0x0005` | 请求数据长度不符 |
| `0x0006` | 请求数据量超限 |
| `0xC050` | **数据超出范围（地址越界）** |
| `0xC051` | 命令/子命令错误 |
| `0xC052` | 请求数据区错误 |
| `0xC056` | 不能对指定设备执行 |
| `0xC058` | 请求数据的指定方式错误 |
| `0xC059` | 命令未找到 |
| `0xC05B` | 不能对指定设备执行（保护） |
| `0xC05C` | 命令未找到（软元件指定错） |
| `0xC05F` | 请求数据重复 |
| `0xC060` | 请求数据非法（ASCII 转换错） |
| `0xC061` | 请求数据长度不符 |
| `0xC0B5` | CPU 错误 |
| `0xC200` | 远程 RUN/STOP 未受理 |
| `0xC201` | 远程 RUN/STOP 状态错 |

## 8. 实现坑

1. **ASCII 与二进制不能混**：PLC 侧参数设定决定，发错编码会返回 `0xC059`。
2. **位设备地址 = 地址 × 16 + 位号**（M100 是 `0x0640`，不是 100）。
3. **长度字段位置不直观**（3E 二进制偏移 7，2 字节）—— 重算容易差 2。
4. **4E 帧多了序列号**：iQ-R 常见，用 3E 帧会返回 `0xC059`。
5. **单请求 960 字上限**，大范围读取要分片。
6. **UDP 需自己做重传**（无序列号时无法判断丢包）。
7. **FX5U 走 SLMP 时端口/帧型不同**（5000/5001 + SLMP 4E）。
