# 32 · 标准第 4 部分：数据项定义

> **来源**：标准原文（10 页 PDF，文字版可提取）——`数控装备工业互联通讯协议 第4部分：
> 数据项定义.pdf`（T/CMTBA XXXX.4—××××，**送审讨论稿**）。
> **证据级**：🔵 标准（逐表记录）。
> **本册用途**：模型里能出现哪些**数据项名字**、每个名字的**类型/单位/适用范围**，以及
> 与本仓库适配器实现的**对照**。写点位声明（`adapters/plugins/*.c`）时以本册为准。

NC-Link 全套 7 部分：1 通用技术条件 · 2 联网参考模型 · **3 数控装备模型定义** ·
**4 数据项定义** · 5 终端及接口定义 · 6 安全性 · 7 评价规范。第 4 部分规范性引用第 1、3 部分：
`dict` / JSON 对象 / `list` 的**形状**由第 3 部分规定，本部分只定义**数据项本身**。

## 1. 范围

规定 NC-Link 中**设备对象、组件对象、数据对象**的类型数据项。适用于数控机床、工业机器人、
自动搬运车、清洗设备、检测设备、自动化生产线、自动料库等数控装备（监控传感器/执行器的
工业附属设备参照使用）。

## 4. 数据对象的数据项

数据对象的数据项分三类：**物理量数据项**（表 4）、**通用数据项**（表 6）、**专用数据项**（表 7）。

### 4.1 物理量数据项（表 4，全部是 `number`）

| Type | 默认单位 | 含义 |
|---|---|---|
| `ACCELERATION` | 毫米每秒平方 | 加速度 |
| `ANGLE` | 弧度 | 角位置 |
| `ANGULAR_ACCELERATION` | 角度数每秒平方 | 角加速度 |
| `ANGULAR_VELOCITY` | 角度数每秒 | 角速度 |
| `CONCENTRATION` | 百分数 | 浓度 |
| `CONDUCTIVITY` | 西门子每米 | 导电力 |
| `CURRENT` | 安培 | 电流 |
| `DISPLACEMENT` | 毫米 | 位移 |
| `ENERGY` | 瓦特小时 | 功耗 |
| `FLOW` | 升每秒 | 流体瞬时流量 |
| `FREQUENCY` | 赫兹 | 频率 |
| `LENGTH` | 毫米 | 长度 |
| `MASS` | 千克 | 质量 |
| `POSITION` | 毫米 | 位置 |
| `POWER` | 瓦特 | 功率 |
| `POWER_FACTOR` | 百分比 | 功率因数 |
| `PRESSURE` | 帕斯卡 | 压强 |
| `RESISTANCE` | 欧姆 | 电阻 |
| `SPEED` | 毫米每分钟 | 速度 |

| 默认单位 | 常用非默认单位 | 含义 |

| A | mA、μA | 电流 |
| mm | m、μm | 位移 |
| Wh | kWh、Ws | 功耗 |
| L/s | mL/s | 流体瞬时流量 |
| Hz | kHz、MHz、GHz | 频率 |
| mm | m | 长度 |
| kg | g、mg | 质量 |
| W | kW、mW | 功率 |
| Ω | kΩ、MΩ | 电阻 |
| mm/min | m/min | 速度 |
| ℃ | ℉ | 温度 |
| VA | kVA | 视在功率 |

### 4.3 通用数据项（表 6）

| Type | 类型 | 单位 | 含义 |
|---|---|---|---|
| `CREATE_TIME` | string | 无 | 创建时间 |
| `CREATOR` | string | 无 | 创建者 |
| `MANUFACTURER` | string | 无 | 厂商 |
| `MODEL` | string | 无 | 型号 |
| `NAME` | string | 无 | 名称 |
| `NUMBER` | number | 无 | 编号 |
| `PARAMETER` | dict | 无 | 参数 |
| **`STATUS`** | **string** | 无 | **数控装备、组件运行状态**（取值见表 8） |
| `VERSION` | string | 无 | 版本 |
| `WARNING` | JSON 对象 | 无 | 报警信息（形状见表 9） |

> **只有 `STATUS` 这一个运行状态项**：它没有 `STATUS@xxx` 这种子项，取值是
> `running` / `free` / `holding`（表 8）。协议私有的位域（某型号的编辑/移动/急停位…
> 属于厂商私有，不能占用 `STATUS` 这个名字）。

### 4.5 组合定义（表 8）

数据对象的 `type` 取特定值时，`value` 的取值集合：

| 数据对象 type | value 取值 | 类型 | 含义 |
|---|---|---|---|
| `TYPE` | `rotary` | string | 旋转轴 |
| `TYPE` | `linear` | string | 线性轴 |
| `STATUS` | `running` | string 或整数 `0` | 运行 |
| `STATUS` | `free` | string 或整数 `1` | 空闲 |
| `STATUS` | `holding` | string 或整数 `2` | 紧急保持（产线上等上料即处于此态） |
| `WORK_MODE` | `manual` | string | 手动 |
| `WORK_MODE` | `auto` | string | 自动 |

| 数据对象 type | JSON 元素 | 类型 | 含义 |
|---|---|---|---|
| `COORDINATE` | `x,y,z` | number | 线性轴坐标系 |

| | `u,v,w` | number | 摆动轴坐标系 |
| | `x1,y1,z1 … xn,yn,zn` | number | 多通道线性 |
| | `a1,b1,c1 … an,bn,cn` | number | 多通道旋转 |

## 5. 与本仓库实现的对照

### 5.1 已经一致的

- 设备节点的 `device.type` = `MACHINE`（`conf/fanuc.json`）与表 1 一致。
- 模型路径的**首段**用 `MACHINE`（本次把 `/CNC/...` 改成 `/MACHINE/...`：`CNC` 不是
  标准里的类型名，设备对象只有表 1 那七个取值）。
- `POSITION`、`SPEED` 是表 4 的物理量数据项 ✓（FANUC 适配器读的 `ACTF`/`ACTS` 正是
  位置与速度）。

### 5.2 与标准不一致、要改的（FANUC 适配器现状）

| 当前点位 | 标准 | 处理 |
|---|---|---|
| `/MACHINE/STATUS@MANUAL` `@RUN` `@EDIT` `@MOTION` `@MSTB` `@EMERGENCY` `@ALARM` `@SPINDLE` `@OPERATOR` `@DUMMY` `@AUTO`（11 条） | 表 6 只有一个 `STATUS`，取值 `running`/`free`/`holding`（表 8） | FOCAS 的 ODBST 位域是**厂商私有**的：要么映射成标准 `STATUS` 的三态（粗粒度），要么另起私有名字（不能叫 `STATUS`） |
| `/MACHINE/STATUS@ALARM` | 报警是表 6 的 `WARNING`（JSON 对象，表 9：`number`/`text`/`key_value`） | 报警改走 `WARNING`（FOCAS 侧要读报警号/文本才够） |
| `/MACHINE/PART_COUNT`（int32） | 表 7：`PART_COUNT` 是 **string** | 名字对，**类型要改成 string** |
| `/MACHINE/PROGRAM@NAME` | 表 7：`PROGRAM`（主程序名，string）/ `PROGRAM_NUMBER`（当前程序号，number） | 改名为 `PROGRAM`（`@NAME` 是自造后缀） |
| `/MACHINE/AXIS@0/POSITION`、`AXIS@1/…`、`AXIS@2/…` | 表 2/表 3：组件 `AXIS` 的 `number` 是 `X`/`Y`/`Z`（线性）、`A`/`B`/`C`（旋转）、`U`/`V`/`W`（摆动） | 轴名从 0/1/2 改成 X/Y/Z（按实际轴配） |
| `/MACHINE/AXIS@k/SPEED` | 表 4：`SPEED` 默认单位毫米每分钟 | 名字对；单位/换算要按 FOCAS 实际量纲对一次 |

### 5.3 还没定的

- 厂商私有数据项（FOCAS 的 ODBST 各位、刀补、宏变量…）在模型里的**合法写法**：本部分
  只列标准自己的专用项，扩展槽由**第 3 部分（数控装备模型定义）**的模型机制决定
  → 记为待办（见 [31 册](31-待真机抓包清单.md) 同级别的待核对项）。
- 报警从 `STATUS@ALARM` 迁到 `WARNING` 需要 FOCAS 侧读报警号/文本（`cnc_rdalmmsg2` 一类），
  01 册尚未抓到该调用 → 也进待真机清单。
