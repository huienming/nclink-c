## 4. 缺口总表与优先级

| 设备 | 缺失 | 优先级 | 途径 | 预估成本 |
|---|---|---|---|---|
| 科德 GNC62 | 全套协议 | 低 | 现场抓包 / 代理商 | 需客户配合 |
| 北京精雕 | 开发包 | **中** | CSDN 积分下载 | 几十积分 |
| 海康相机 | HCNetSDK | 低 | 海康开放平台注册 | 免费（需外网） |
| （另）GSK | GSKRM.dll | **中** | 广数代理 | 需采购 |
| （另）KND | REST 手册 | **中** | book118 付费 | 几十元 |

**建议**：先花几十元/几十积分解决 **精雕 + KND**（成本极低、收益明确），GSK 走采购流程，科德/海康按项目需求临时攻。

## 5. 通用攻坚方法论（适用于任何缺口协议）

```
① 优先找官方 SDK/DLL → 抽导出表（pefile/dnfile/readelf）→ 得函数名
② 无 SDK → 找现成开源实现（PyPI/GitHub，注意网络通道）
③ 无任何资料 → 现场抓包（tcpdump/Wireshark）→ 报文聚类 → 逐步对应语义
   技巧：
     - 改变机床状态（启动/停止/换程序）同时抓包，比对报文差异定位字段
     - 高频报文 = 坐标/速度；低频 = 状态/报警；事件触发 = 报警
     - 文本协议先找 ASCII 可读串（程序名/路径）；二进制先找长度字段规律
④ 交叉验证：同一语义在其它厂商协议里的实现方式（商业库 49 个报文类可作对照）
⑤ 落地：先只读，验证稳定后再开写
```
