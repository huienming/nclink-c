## 2. 连接建立

```
① TCP connect(ip, 9600)
② FINS/TCP 握手（自动分配节点号，推荐）：
   发送 FINS/TCP 头（20 字节）：46 49 4E 53 ("FINS") + 00 00 00 0C + 00 00 00 00 + 00 00 00 00 + 00 00 00 01
   （命令 0x00000000 = 节点地址自动分配请求）
③ 响应：46 49 4E 53 + ... + 返回分配的客户端节点号
④ 业务命令（FINS 帧）
⑤ 断开
```

**FINS/TCP 帧头**（10 字节，加在 FINS 帧前）：
```
0  4  "FINS" (46 49 4E 53)
4  4  长度（大端，= 后续 8 字节 + FINS 帧长）
8  4  命令：0x00000000=节点分配 0x00000001=数据发送 0x00000002=数据接收 0x00000003=错误 0x00000004=终止
12 4  错误码 + 客户端节点号
```

## 3. FINS 帧格式

```
偏移  长度  字段    说明
0     1    ICF     信息控制域（0x80 = 需要响应；0x00 = 网关）
1     1    RSV     保留（0x00）
2     1    GCT     网关计数（0x02 常见）
3     1    DNA     目标网络地址（0x00 = 本网）
4     1    DA1     目标节点号（PLC 的 FINS 节点，常为 IP 末段）
5     1    DA2     目标单元地址（0x00 = CPU）
6     1    SNA     源网络地址
7     1    SA1     源节点号
8     1    SA2     源单元地址（0x00）
9     1    SID     服务 ID（任意，响应回显）
10    2    命令码   MRC + SRC（大端）
12    N    数据区
```

### 3.1 内存区读（命令 `01 01`）

```
数据区：
  1 字节   区代码
  2 字节   起始地址（大端）
  1 字节   位号（字访问 = 0x00）
  2 字节   数量（大端）

响应：
  1 字节   结束码（00 = 正常）
  2 字节   结束码明细（MRES + SRES）
  N 字节   数据
```

### 3.2 内存区写（命令 `01 02`）

```
数据区：区代码 + 起始地址 + 位号 + 数量 + 写入数据
```

## 4. 区代码表

| 区域 | 码 | 区域 | 码 |
|---|---|---|---|
| **CIO**（I/O 继电器） | `0xB0` | **W**（工作继电器） | `0xB1` |
| **H**（保持继电器） | `0xB2` | **A**（辅助继电器） | `0xB3` |
| **D**（数据内存） | `0x82` | **P**（扩展数据内存） | `0x87` |
| **E** 区（EM 数据内存） | `0x90`+ 库号 | **C**（计数器） | `0x89` |
| **T**（定时器） | `0x83` | **CF**（当前计数器值） | `0xA5` |
| **TS**（定时器完成标志） | `0x85` | **CS**（计数器完成标志） | `0x84` |
| **IR/DR**（索引/数据寄存器） | `0xDC`/`0xBC` | **TK**（任务标志） | `0xB4` |

**EM 区库号**：`E0_0`–`E0_15` 用 `0x20`–`0x2F`；`E1_0`–`E1_15` 用 `0x50`–`0x5F`（详情见欧姆龙 W340 手册）

## 6. 执行流程（读 D100 起 10 字）

```
FINS/TCP 头: "FINS" + 长度 + 00 00 00 01
FINS 帧:
  80 00 02 00 <DA1> 00 <SNA> <SA1> 00 <SID>
  01 01                      # MRC=01 内存区读
  82                         # 区代码 D
  00 64                      # 起始地址 100（大端）
  00                         # 位号 0（字访问）
  00 0A                      # 数量 10
响应:
  ... 00 00 00 (结束码=00/00/00 正常) + 20 字节数据（10 字 × 2 字节，大端）
```

## 7. 错误码

| 结束码 | 含义 |
|---|---|
| `0x00` | 正常 |
| `0x01` | 未找到本地节点 |
| `0x02` | 令牌超时 |
| `0x03` | 重发超限 |
| `0x04` | 超时 |
| `0x05` | 节点地址范围错 |
| `0x10` | 命令格式错 |
| `0x11` | 参数错 |
| `0x20` | **读取不可能（地址越界/区不存）** |
| `0x21` | **写入不可能** |
| `0x22` | 当前运行模式不允许 |
| `0x23` | 单元不存在 |
| `0x24` | 起始地址 + 数量越界 |
| `0x25` | 数据长度不符 |
| `0xA3` | 数据被中止 |
| `0xA4` | 服务被中止 |
| `0xA5` | 服务被拒绝（CPU 忙） |
| `0x2601` | 未开放（PLC 未进入 MONITOR/RUN） |

## 8. 实现坑

1. **FINS/TCP 需要先做节点地址分配**（命令 `0x00000000`），否则后续帧被拒 —— 这是与 UDP 最大的区别。
2. **`DA1` 目标节点号 = PLC 的 FINS 节点**（常为 IP 最后一段，但可在 PLC 侧改）；`SA1` = 本机节点（节点分配时返回）。
3. **大端**：所有 16 位字段（地址、数量）都是大端。
4. **位访问**：字访问时"位号"字节填 0x00；位访问填 0x00-0x0F。
5. **EM 区库号复杂**（`0x20`-`0x2F` / `0x50`-`0x5F`），别按 `0x90` 硬编码。
6. **单请求上限 999 字**（约 2000 字节）。
7. **CJ2/NJ 的 FINS 需要 PLC 侧开启 FINS 服务**并配置 UDP/TCP 端口。
