# 11 · 兄弟 Brother（原生 TCP 命令协议）实现规格书

> **证据**：🟢 参考实现二进制抽取（10 条固定宽度命令）· 🔵 公开文章实测报文
> **定位**：Brother 机床（Speedio / TC 系列）自带 TCP 服务，**文本命令式，实现极简**

---

## 2. 帧格式

```
请求：  %<CMD> <参数>\r\n%
        ↑ 9 字符定宽命令（不足补空格）
响应：  数据内容 + \r\n%%   或  错误码
```

**实测样例**（抓包验证）：
```
→ %CLOD WKCNTR \r\n%
← <工件计数文件内容>
```

> 注意：命令是 **9 字符定宽**（含补齐空格），不是变长的——这是从参考实现二进制里发现的固定宽度字符串表。

### 3.1 各数据项的实测请求帧（🟢 本地仿真抓取，2026-09）

跑现场 Go 网关 + 假机床（端口 10000）逐项抓到的真实请求——**印证了 §3 的命令表**，
并给出帧的排法（`%` + 命令 8 字符空格补齐 + 参数 8 字符 + `00` + CRLF + 参数行 +
CRLF + CRLF + 计数 + `%`）：

| 项 | 请求（ASCII，`\r\n` 即回车换行） |
|---|---|
| `GetCurProgName` | `%CREDPRGN` + 8 空格 + `00\r\n\r\n01%` |
| `GetToolList` | `%CLOD    ATCTL   00\r\n\r\n01%` |
| `PWD` | `%CFLDPWD` + 8 空格 + `00\r\n\r\n01%` |
| `LS` | `%CFLDDRQ` + 8 空格 + `00\r\n\r\n01%` |
| `CD /` | `%CFLDCHG` + 8 空格 + `00\r\n/\r\n\r\n03%` |

逐字节例（`GetCurProgName`，26 字节）：

```
25 43 52 45 44 50 52 47 4e 20 20 20 20 20 20 20  "%CREDPRGN       "
20 30 30 0d 0a 0d 0a 30 31 25                       " 00....01%"
```

也就是：命令与参数各占 8 字符（空格补齐），后面跟 `00`、CRLF；带参数的（如 `CD`）
把参数写在第二个 CRLF 之前；帧尾是两位十进制计数 + `%`（实测 01、03，随命令推进）。
`GetMaintenanceData` 需要额外参数（网关报 `The Param field is required`），
`GetFileList`/文件类命令按同一排法带参数即可。

### 3.2 应答形状（🟢 2026-09，`tools/site-probe/brother_reply_probe2.sh`）

反汇编 `hp2x/protocols/brother/cnc.responseIsOk`（`0x617704`）与 `filterResData`
（`0x617324`，里面那句 `request error,response: %s` 就是之前一直看到的报错）——
应答的判定只有三条：

```
① 按 \r\n 切开后至少 2 段；
② 第 1 段 ≥ 19 字节，且**以 ASCII "00" 结尾**（就是请求第一行的排法，19 字节正好）；
③ 整包的**最后一个字节是 `%`**。
```

**应答模板**：

```
<请求第一行原样 19 字节> \r\n <数据> \r\n %
```

（19 = `%` + 8 字符命令 + 8 字符参数 + `00`；照抄请求的前 19 字节即可。）

实测（同一套探针）：

| 项 | 数据区摆法 | 返回 |
|---|---|---|
| `PWD` | `/` · `/O1000` | `'/'` · `'/O1000'` ✅（整段文本） |
| `GetCurProgName` | `ABCD` · `ABCDE` · `ABCDEF` | 都是 `'ABCD'` —— 这一项驱动**只取数据前 4 字节**（<4 字节直接 panic `[:4] with length N`） |
| `LS` | `DIR1…DIR2` | `['<整段>']`（列表里一项） |
| `GetToolList` | `T01,1;T02,2` / `1,T01;2,T02` / `T01=1;…` | `{}` —— 工具表的字段排法还没试出来 |

**注意**：`request error,response: <内容>` 只说明上面 ①② 没过（第 1 段尾巴不是
`00`、或第 1 段太短），**不是**报文内容错——之前就是卡在这里。

**剩下的两个**（`GetToolList` / `GetMaintenanceData`）在 §3.3 已闭环。

### 3.3 工具表 / 保养数据也闭环了（🟢 2026-09，`tools/site-probe/brother_{maint,tool}_probe.sh`）

#### 3.3.1 请求（26 字节定长，🟢 实测）

```
%CLOD    PRDC2   00 \r\n \r\n 01 %          → 26 字节
└─ 9 ────┘└─ 8 ──┘└ 3 ┘
```

即 `%` + `CLOD` + 4 空格 + **命令 6 字符左对齐补空格** + `00` + CRLF + CRLF + `01` + `%`。
`GetMaintenanceData` 的 `param` → 命令（🟢 实测；Lua 侧 [brother_mod.lua](#) 的注释与之一一对应）：

| param | 命令 | 含义（Lua 里取的键） |
|---|---|---|
| 9 | `PRDC2` | 生产数据 2（切削时间 `L01`） |
| 10 | `PRD3` | 生产数据 3（状态历史 `C01`） |
| 11 | `MONTR` | 生产数据 4（计数器 `C01` / 时间 `T01`） |
| 12 | `MAINTC` | 维护保养（`Q01`–`Q16`） |
| 23 | `PDSP` | 位置数据（`X01` 进给/倍率/刀具、`P01/P02/P03` 坐标） |
| 25 | `ALARM` | 报警（`E01`） |

`GetToolList` 用 `ATCTL`（同为 26 字节，同一模板）。命令名表在二进制字符串区里还有
`PRD1` · `SYSC89`–`SYSC99` · `PLCDAT` · `PLCMON` · `VER` · `TCUT` · `WKCNTR` · `WVPRM` ·
`IO` · `OVERRIDING` · `PAINT` · `PANEL` · `SAVEPOINT` · `RST_STREAM` 等。

#### 3.3.2 应答（🟢 闭环）

```
<真实请求的前 19 字节，原样回显> \r\n <数据行 1> \r\n <数据行 2> … \r\n 00 \r\n %
数据行 = <键>,<值 1>,<值 2>,…（逗号分隔）
```

三个要点（都是实测踩出来的）：

1. **第一段必须是真实请求行**（19 字节、末两字节 `00`）。手写字符串不行 ——
   `PWD` 的真实请求是 `%CFLDPWD         00`，不是 `%CLOD    PWD     00`。
   探针里用 `mock.py` 的 `ZREP`（拷贝请求前 24 字节再打补丁）最省事：
   `ZREP:N,19:0d0a,21:<数据>,<21+len>:0d0a25`。
2. **数据块要以一行 `00` 收尾**：没有它，**最后一行会被丢掉**（实测 3 行只回 2 行，
   补一行 `00` 后 3 行全回）。空行会造出一个空键（`{'': []}`），数据里别留空行。
3. 键就是"逗号前那一段"；值是其后的字符串数组。**首字段为 `0` 的行会被驱动丢弃**
   （和 Lua 里 `v[1] ~= "0"` 的过滤是同一个意思）。

实测结果：

```
GetToolList（ATCTL）
  M01,1,0,0,1,0 / M02,2,0,0,1,0 / M03,3,0,0,1,0 / 00
  → {"M01":["1","0","0","1","0"], "M02":[…], "M03":[…]}

GetMaintenanceData(23)（PDSP）
  X01,100,2,3,7,5,6,7,8,9,10,100,80,70 / 00
  → {"X01":["100","2","3","7","5","6","7","8","9","10","100","80","70"]}
  X01(13 值) + P01(3) + P02(3) + P03(3) / 00
  → {"X01":[…], "P01":[…], "P02":[…], "P03":[…]}
```

工具表的 5 个字段与 Lua 的语义（§4 表里的 `M01`–`M51`）：`number`（0 未设定 /
1–99 刀号 / 255 盖设置）、`state`（0 对话 / 1 NC）、`tool_group_number`（NC 组号或
对话主刀具号）、`type`（1 标准 / 2 大直径 / 3 中等直径）、`color`（0 无颜色）。

保养数据的字段下标（`X01`，来自 `brother_mod.lua`）：`[1]` 进给速度、`[4]` 主轴刀具号、
`[11]` 快速倍率、`[12]` 进给倍率、`[13]` 主轴倍率；`P01/P02/P03` = 机械/相对/绝对坐标
（`P02` 指令位置、`P03` 实际位置，`/AXIS@5/*` 用第 6 个元素取旋转轴）。

## 5. 实现要点

```
① TCP connect(ip, 10000)
② 发命令：b"%CLOD WKCNTR \r\n%"
③ 读响应（以 \r\n%% 结尾判定结束）
④ 解析文本
⑤ 无会话概念 —— 每次独立；无心跳需求
```

---

## 6. 实现坑

1. **9 字符定宽**：`%CDRQALAL` 正好 9 字符，其余命令要补空格到 9（如 `%CLOD` → `%CLOD` 后跟 5 空格？实测样例是 `%CLOD WKCNTR `，命令与参数间有空格）。
2. **结束符判定**：响应以 `\r\n%%` 结尾；大文件需要循环读直到出现该标记。
3. **无错误码规范**：异常靠文本内容判断，健壮性要自己加。
4. **写/删命令危险**（`%CSAV` / `%CDEL` / `%CFLDDEL`）—— 生产默认禁用。
5. **机床侧需开启以太网功能**（参数配置）。
