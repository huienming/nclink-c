## 2. 帧格式

```
请求：  %<CMD> <参数>\r\n%
        ↑ 9 字符定宽命令（不足补空格）
响应：  数据内容 + \r\n%%   或  错误码
```

**实测样例**（抓包验证）：
```
→ %CLOD WKCNTR \r\n%
← <工件计数文件内容>
```

> 注意：命令是 **9 字符定宽**（含补齐空格），不是变长的——这是从参考实现二进制里发现的固定宽度字符串表。

### 3.1 各数据项的实测请求帧（🟢 本地仿真抓取，2026-09）

跑现场 Go 网关 + 假机床（端口 10000）逐项抓到的真实请求——**印证了 §3 的命令表**，
并给出帧的排法（`%` + 命令 8 字符空格补齐 + 参数 8 字符 + `00` + CRLF + 参数行 +
CRLF + CRLF + 计数 + `%`）：

| 项 | 请求（ASCII，`\r\n` 即回车换行） |
|---|---|
| `GetCurProgName` | `%CREDPRGN` + 8 空格 + `00\r\n\r\n01%` |
| `GetToolList` | `%CLOD    ATCTL   00\r\n\r\n01%` |
| `PWD` | `%CFLDPWD` + 8 空格 + `00\r\n\r\n01%` |
| `LS` | `%CFLDDRQ` + 8 空格 + `00\r\n\r\n01%` |
| `CD /` | `%CFLDCHG` + 8 空格 + `00\r\n/\r\n\r\n03%` |

逐字节例（`GetCurProgName`，26 字节）：

```
25 43 52 45 44 50 52 47 4e 20 20 20 20 20 20 20  "%CREDPRGN       "
20 30 30 0d 0a 0d 0a 30 31 25                       " 00....01%"
```

也就是：命令与参数各占 8 字符（空格补齐），后面跟 `00`、CRLF；带参数的（如 `CD`）
把参数写在第二个 CRLF 之前；帧尾是两位十进制计数 + `%`（实测 01、03，随命令推进）。
`GetMaintenanceData` 需要额外参数（网关报 `The Param field is required`），
`GetFileList`/文件类命令按同一排法带参数即可。

### 3.2 应答形状（🟢 2026-09，`tools/site-probe/brother_reply_probe2.sh`）

反汇编 `hp2x/protocols/brother/cnc.responseIsOk`（`0x617704`）与 `filterResData`
（`0x617324`，里面那句 `request error,response: %s` 就是之前一直看到的报错）——
应答的判定只有三条：

```
① 按 \r\n 切开后至少 2 段；
② 第 1 段 ≥ 19 字节，且**以 ASCII "00" 结尾**（就是请求第一行的排法，19 字节正好）；
③ 整包的**最后一个字节是 `%`**。
```

**应答模板**：

```
<请求第一行原样 19 字节> \r\n <数据> \r\n %
```

（19 = `%` + 8 字符命令 + 8 字符参数 + `00`；照抄请求的前 19 字节即可。）

实测（同一套探针）：

| 项 | 数据区摆法 | 返回 |
|---|---|---|
| `PWD` | `/` · `/O1000` | `'/'` · `'/O1000'` ✅（整段文本） |
| `GetCurProgName` | `ABCD` · `ABCDE` · `ABCDEF` | 都是 `'ABCD'` —— 这一项驱动**只取数据前 4 字节**（<4 字节直接 panic `[:4] with length N`） |
| `LS` | `DIR1…DIR2` | `['<整段>']`（列表里一项） |
| `GetToolList` | `T01,1;T02,2` / `1,T01;2,T02` / `T01=1;…` | `{}` —— 工具表的字段排法还没试出来 |

**注意**：`request error,response: <内容>` 只说明上面 ①② 没过（第 1 段尾巴不是
`00`、或第 1 段太短），**不是**报文内容错——之前就是卡在这里。

**还没闭环**：`GetToolList`（工具表）与 `GetMaintenanceData`（保养数据）的字段排法，
继续用同一个探针扫数据区即可。

## 5. 实现要点

```
① TCP connect(ip, 10000)
② 发命令：b"%CLOD WKCNTR \r\n%"
③ 读响应（以 \r\n%% 结尾判定结束）
④ 解析文本
⑤ 无会话概念 —— 每次独立；无心跳需求
```

---

## 6. 实现坑

1. **9 字符定宽**：`%CDRQALAL` 正好 9 字符，其余命令要补空格到 9（如 `%CLOD` → `%CLOD` 后跟 5 空格？实测样例是 `%CLOD WKCNTR `，命令与参数间有空格）。
2. **结束符判定**：响应以 `\r\n%%` 结尾；大文件需要循环读直到出现该标记。
3. **无错误码规范**：异常靠文本内容判断，健壮性要自己加。
4. **写/删命令危险**（`%CSAV` / `%CDEL` / `%CFLDDEL`）—— 生产默认禁用。
5. **机床侧需开启以太网功能**（参数配置）。
