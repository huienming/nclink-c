## 3. P0 缺口详表（含协议线索）

### 3.1 华中数控 HNC-8 / HNC-9 —— ⛔ **已评估否决**

**否决结论**：**不纳入实现范围**。
**否决理由**（2026-09）：
1. `hncAPI` 本体是 **Windows-only DLL**（`hccapi.dll`），无法在 Linux/跨平台侧自实现；
2. **必须部署厂商上位机软件**才能工作 —— 属于"买软件+装 Windows"的门槛，不是可独立实现的协议；
3. 不符合本套规格书的核心基准：**跨平台 + 免授权 + 可自实现**。

**对比**：同样是国产头部，**广数（GSK）**有 Modbus 路线、**凯恩帝（KND）**有 REST 接口、**新代（Syntec）**有 RemoteCNC —— 都能跨平台自实现；华中三条路线（串口/以太网直读、OPC UA、hncAPI）中前两条资料不公开、第三条锁死 Windows。

> 华中数控 HNC（已否决）的原始调研未随本目录提供（若后续有 Windows 侧需求可取回）。

**保留的原调研要点**（供决策参考）：

| 项 | 内容 |
|---|---|
| 地位 | **国产数控第一梯队**（航天/军工优先采购），国内项目绕不开 |
| 架构 | `HMI 层 / NCAPI 层 / NCU 层` 三层 |
| 传输 | **TCP/IP + SDK 软件包**（C++/C# 示例） |
| 端口 | **5000-6000**（默认 IP 192.168.1.100） |
| 特性 | **2017 年后版本支持 1ms 实时采集** |
| 资料 | 《HNC-8 数控系统二次开发》（含 API 层说明）· 《HNC-8 用户说明书》 |
| 获取途径 | 华中数控官网/代理商索要二次开发手册；CSDN 有实战文章 |

## 4. P1/P2 补充说明

### 4.1 DCS 家族（和利时/中控/优稳/科远/横河/霍尼韦尔）
统一走 **OPC DA / OPC UA**（网关清单实测支持）——**一套 OPC 客户端通吃**，与 04/19 册共用实现。优先级：中。

### 4.2 国产运动控制/切割（维宏、柏楚）
- **维宏**：有"维宏云"，官方提供**基于 IP 网络的通信协议**与数据采集
- **柏楚 CypCut**：激光切割控制系统龙头（CypCutPro/CypCutE）
- 赛道：激光/水刀/雕刻切割，与金属切削机床不同，但**客户量大**

### 4.3 工业以太网网关方案（CC-Link IE / PROFINET / EtherCAT）
不走"直接采集"，走**协议网关转换**（PROFINET↔CC-Link IE 网关已是成熟产品）——对 CaNC 的意义是：**支持网关接入 = 一次覆盖多个品牌**。

### 4.4 国产 PLC 长尾（南大傲拓/步科/亿维/联诚）
多数基于 **Modbus 或自有协议**；商业库 已覆盖台达/信捷/汇川/麦格米特/丰炜/永宏（有地址映射实现），我方可直接整理成册。

## 4.5 品牌纳入准则（2026-09 确立）

经华中数控一例，明确本套规格书收录品牌的**三条硬门槛**（缺一不可）：

| 准则 | 含义 | 反例 |
|---|---|---|
| **跨平台** | 协议/Library 能在 Linux（ARM/x86）上实现或调用 | ⛔ 华中 hncAPI（Windows DLL） |
| **免授权** | 不需要购买厂商 SDK/授权，或 SDK 可公开获取 | ⚠️ 马扎克 MTConnect（~8k 授权）、大隈 DevelopKit（需渠道） |
| **可自实现** | 协议能独立实现，不依赖厂商上位机软件常驻 | ⛔ 华中（需厂商上位机） |

> **含义**：马扎克/大隈/发格三个待补品牌，**入库前需先验证是否满足这三条**——否则同样应否决。宁可少而可落地，不要多而锁死。
> **已于 2026-09 完成核验，结果见 §4.6（马扎克 ✅ / 发格 ✅ / 大隈 ⛔）**

### 4.6 待补品牌门槛核验（2026-09 完成）

按 §4.5 三条硬门槛逐一核验，**2 通过 / 1 否决**：

| 品牌 | 跨平台 | 免授权 | 可自实现 | 结论 | 依据 |
|---|---|---|---|---|---|
| **马扎克 MAZAK** | ✅ | ✅ | ✅ | **✅ 通过（限 Smart/Smooth）** | **TCP 直连**：纯 Socket、无需 DLL、跨平台（Linux/ARM/单片机）、端口 **50100**、开 **IOP4.0=1**（Smart 为 IOP5，解锁码 1131）；可规避官方 MT 授权（~¥1.2 万） |
| **发格 FAGOR** | ✅ | ✅ | ✅ | **✅ 通过** | **CNC 宏程序 TCP 主动上报**：官方原生宏函数 **`TCPOPEN`**，**无授权、无硬件加装**；采集端只监听端口（例 **8899**） |
| **大隈 OKUMA** | ✗ | ⚠️ | ✗ | **⛔ 否决** | **DevelopKit 为 Windows 程序**（"程序运行在普通 Windows 电脑上"）；跨平台免授权方案清单（fanuc/三菱/西门子/海德汉/马扎克/兄弟/哈斯/广数/KND）**不含大隈**；OSP 系统相对封闭 |

**马扎克的重要限定**：
- ✅ **Smart / Smooth（smooth-c/g/x）** → TCP 直连路线合格
- ⛔ **640 / MATRIX（nexus/nexu2）** → 只能"Windows 装采集插件 + UDP 上报"，**不满足跨平台**
- ⛔ DLL 调用路线：**仅限 Windows 32 位程序**

**大隈否决后的替代价值**：其业务价值由 **FANUC 系统机型**承接（北一大隈部分机型用发那科，见 [01 册](01-FANUC-CNC-FOCAS.md)）。

**已出分册**：马扎克 [26 册](26-马扎克MAZAK.md) · 发格 [27 册](27-发格Fagor.md)
